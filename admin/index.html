Connect to your repository

Everything you add here is committed to the site repository through GitHub's API. The token is stored only in this browser.

How to create the token (2 minutes)
  1. GitHub → your avatar → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it "site dashboard". Expiration: up to 1 year. Repository access: Only select repositories → pick the site repo.
  3. Permissions → Repository permissions → Contents: Read and write. Everything else stays "No access".
  4. Generate, copy the token (starts with github_pat_), paste it above, click Test & save.
