How this works

Every save makes one commit to the GitHub repo; the site rebuilds itself in about 3 minutes and the build pill in the header turns green when it's live. Images get a fresh file name on upload so you never see a stale cached copy.

Connect to your repository

Changes are committed through GitHub's API. The token is stored only in this browser.

How to create or edit the token
  1. GitHub → avatar → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Repository access: Only select repositories → the site repo.
  3. Repository permissions → Contents: Read and write, Actions: Read and write (lets the dashboard show build status and trigger rebuilds).
  4. Generate / Save, paste here, Test & save.
